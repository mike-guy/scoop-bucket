# mike-guy/scoop-bucket

[Scoop](https://scoop.sh/) packages for Windows, for tools by [mike-guy](https://github.com/mike-guy).

## Install

```powershell
scoop bucket add mike-guy https://github.com/mike-guy/scoop-bucket
scoop install mike-guy/azskufinder
```

## Packages

| Package | Description |
|---|---|
| [azskufinder](https://github.com/mike-guy/azskufinder) | Find the Azure VM sizes you can actually deploy |

## Updates and issues

The manifests in `bucket/` are written automatically by each project's release
workflow, so please don't edit them by hand. `scoop update azskufinder` picks
up new releases.

To report a problem with a package, please open an issue in that project's
repository, for example
[azskufinder's issues](https://github.com/mike-guy/azskufinder/issues).
